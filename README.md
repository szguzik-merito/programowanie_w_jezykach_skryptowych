# 📚 Projekt: Biblioteka (Program w Terminalu)

## 📌 Opis Projektu
Celem projektu jest stworzenie aplikacji terminalowej zarządzającej biblioteką. Program umożliwia przechowywanie informacji o książkach, zarządzanie ich wypożyczeniami, rejestrację studentów oraz przypominanie o zwrotach.

---

## 🎯 Wymagania

### 🔹 Lista Książek (Minimum 25)
Każda książka powinna zawierać następujące informacje:
- **Autor**
- **Tytuł**
- **Rok wydania**
- **Ilość stron**
- **Ilość egzemplarzy dostępnych w bibliotece**

### 🔹 Funkcjonalności:
- 📌 **Dodawanie nowej książki**
- ✏️ **Edycja istniejących książek**
- 🗑 **Usuwanie książek**

### 🔹 Wypożyczanie książek:
- 📚 Każdy student może wypożyczyć **maksymalnie 5 książek jednocześnie**.
- 📋 Lista studentów powinna mieć **maksymalnie 15 zapisanych użytkowników**.

### 🔹 Przypomnienia o zwrotach:
- ⏳ Moduł generujący raport przypominający studentom o konieczności zwrotu książek (wyświetlany w terminalu).

---

## 📝 Wymagania Techniczne i Organizacyjne

### 🔹 Oddanie projektu
Projekt należy oddać poprzez repozytorium **GIT** (np. GitHub, GitLab, Bitbucket).

### 🔹 Terminy oddania:
- **Pierwszy termin** – ostatni dzień zajęć.
- **Drugi termin** – zgodnie z ustaleniami uczelni.

### 🔹 Forma oddania:
Link do repozytorium należy wysłać na adres e-mail:

#### 📌 Temat wiadomości:
```
Nazwa przedmiotu, Imię numer indeksu, numer grupy
```

---

## 🎯 Powtarzanie przedmiotu, sesja poprawkowa, warunek itp.
W przypadku konieczności powtarzania przedmiotu, sesji poprawkowej lub warunkowego zaliczenia, obowiązuje wykonanie tego samego zadania. 

📅 **Termin oddania ustalany jest indywidualnie** poprzez kontakt e-mailowy. Aby rozpocząć proces zaliczenia, należy skontaktować się z wykładowcą i oczekiwać na wiadomość zwrotną z ustaloną datą oddania projektu.

---

## 🎯 Podsumowanie
Projekt biblioteki w terminalu to aplikacja umożliwiająca zarządzanie książkami, studentami oraz wypożyczeniami. Kluczowe elementy to kontrola liczby wypożyczonych książek, ograniczenie liczby studentów oraz system przypomnień o zwrotach. Całość powinna być zapisana w repozytorium GIT i przesłana zgodnie z ustalonym formatem.
